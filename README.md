# Dihhz MMORPG

Portal de jogos e notícias em português, desenvolvido em HTML, CSS e JavaScript.

## Páginas

- `index.html`: destaque e cards da home.
- `jogos.html`: catálogo dos jogos publicados.
- `noticias.html`: matérias por ordem de publicação.
- Páginas de Albion Online, AION 2, ArcheAge Chronicles e Corepunk.

Abra `index.html` no navegador para visualizar localmente. Não há etapa de compilação.

As imagens dos jogos pertencem aos respectivos titulares. As matérias incluem links para as fontes oficiais. As informações refletem a data de consulta indicada em cada publicação.

## Publicação

Site estático compatível com GitHub Pages. Publique a raiz da branch principal.
